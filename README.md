# Ocean Oak Enterprises — website prototype

A static, responsive website with an interactive **illustrative** balanced-scorecard dashboard. It does not collect visitor data, connect to analytics, store leads, or provide real-world performance results.

## Publish with GitHub + Vercel

1. Create a GitHub repository named `oceanoak-enterprises` and initialize with a README if desired.
2. Extract the ZIP. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the **root** of the repository using **Add file → Upload files → Commit changes**. Replace the initial README if prompted.
3. In Vercel, select **Add New → Project → Import Git Repository** and import `oceanoak-enterprises`.
4. Choose **Framework Preset: Other**, **Root Directory: ./**. Leave build command empty; deploy.
5. Vercel gives you a `.vercel.app` address. In the project open **Settings → Domains**, add `oceanoakenterprises.com`, and follow Vercel's DNS instructions at your domain registrar. Add `www.oceanoakenterprises.com` if desired.

## Before launch

- Replace Oak's placeholder biography with a verified résumé, actual technical stack, achievements and a headshot.
- Replace `hello@oceanoakenterprises.com` mailto links with a confirmed working inbox.
- Connect analytics (e.g. GA4) and define consent, event tracking and privacy policy appropriate to jurisdiction.
- Connect any real business data via secure APIs/server-side integrations; don't place API secrets in client JavaScript.
- Replace illustrative scorecard figures with validated source data and date ranges; define metrics and attribution assumptions.
- Review SEO, accessibility, legal notices, and case-study permissions.


## KPI Lab

`kpi.html` is an interactive scenario planner linked in the main navigation. `kpi.css` and `kpi.js` power the page. The figures are synthetic and no live analytics are collected.
